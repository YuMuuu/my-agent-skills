# commit-message

staged された変更から commit message を作成する skill です。
日本語の Conventional Commits 形式を使用します。

## 参考

[`zsh-select-commit-prefix.plugin.zsh`](https://github.com/YuMuuu/zsh-select-commit-prefix/blob/master/zsh-select-commit-prefix.plugin.zsh)を参考に、次の prefix だけを使用する。

`build`、`chore`、`ci`、`docs`、`feat`、`fix`、`perf`、`refactor`、`revert`、`style`、`test`

Conventional Commits の仕様は次のとおりです。

https://www.conventionalcommits.org/ja/v1.0.0/
