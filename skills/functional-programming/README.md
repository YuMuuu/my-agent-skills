# functional-programming

この skill は、厳格な関数型言語に限らず適用できます。
複数の言語で使える原則をまとめたものです。

純粋関数、参照透過性、イミュータブルなデータ、副作用の分離、全域関数、ADT、畳み込みなど、コード生成やコードレビューで利用しやすい考え方を扱います。

Haskell のような純粋な関数型言語を基準にします。
ただし、Haskell の書き方をそのまま強制するものではありません。
